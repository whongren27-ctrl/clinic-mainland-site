# 诊所 AI 可见度增长落地页

中国大陆版诊所 SEO / AEO / GEO 营销落地页前端项目。页面内容已按大陆搜索与 AI 场景重写，AI 模型使用豆包、Kimi、DeepSeek，咨询入口统一导向微信。

## 本地运行

```bash
npm install
npm run dev
```

打开本地预览地址：

```text
http://localhost:3000/
```

## 生产构建

```bash
npm run build
```

## 主要页面内容

- 首屏转化 CTA 与 AI 问答模拟
- 搜索、AEO、GEO 与微信承接逻辑
- 服务优势与执行模块
- 患者提问案例
- 年度方案
- FAQ
- 微信咨询导流收口
